# AutoMarket

A repository for the final project. It is an application (AutoMarket) for selling used vehicles. Listings are created by filling out a form with a wide variety of characteristics to choose from, such as the make, model, mileage, color, fuel type, and transmission. The app includes functions such as vehicle search and result sorting, updating, deletion, a contact form, and translation. The app will be created with Node.js in Visual Studio Code, pgAdmin, and Bootstrap Studio.
